## 2. 제품 요약 (엘리베이터 피치)

**한 문장:**
만톡은 생년월일을 입력하면 정밀한 만세력을 자동 계산하고, AI 상담사와 채팅하며 사주를 풀어보는 모바일 앱입니다.

**세 문장:**
기존 사주 앱은 긴 텍스트 리포트를 한 번에 쏟아내고 끝납니다. 만톡은 다릅니다. 사용자가 궁금한 것을 자유롭게 물어보면 AI가 사주 데이터를 바탕으로 대화형 상담을 이어가며, 마치 진짜 역술인과 이야기하는 것 같은 경험을 제공합니다.

## 3. 핵심 차별점 (USP)

### 차별점 1: 대화형 사주 상담 (핵심)
- **기존 앱**: 입력 → 긴 리포트 → 끝
- **만톡**: 입력 → AI와 끝없는 대화 → 추가 질문 → 맥락 기반 후속 답변
- 사주 앱 중 유일한 실시간 대화형 상담 구조

### 차별점 2: 9종 AI 캐릭터 페르소나
- 귀여운 친구, 친근한 언니(기본), 현명한 학자, 할머니, 아기 스님, 시나리오 작가, 신입 무당, 사주 책, 새옹지마
- MBTI 4분면 기반(NF 감성형 / NT 분석형 / SF 친근형 / ST 현실형) 매핑
- 사용자 취향에 맞는 상담 톤 선택 가능

### 차별점 3: 이중 AI 엔진
- **GPT-5.2**: 사주 심층 분석 (정확도)
- **Gemini 3.0 Flash**: 실시간 스트리밍 대화 (자연스러움)
- DALL-E / Imagen: AI 생성 이미지
- 분석의 정확성과 대화의 자연스러움을 동시에 확보

### 차별점 4: 정밀한 만세력 계산
- 25개 한국 도시별 진태양시(真太陽時) 보정
- 절입시간(節入時間) 정밀 계산
- 음양력 변환 (1900~2100년, 윤달 포함)
- 서머타임 보정, 야자시/조자시 구분

### 차별점 5: 맥락을 기억하는 상담
- 과거 대화와 사주 데이터를 바탕으로 연속 상담
- "지난번에 이직 고민 얘기했었지?" 같은 맥락 유지
- ChatGPT 스타일 대화 히스토리

### 인구통계

| 항목 | 내용 |
|------|------|
| 연령대 | 20~40대 |

| 직업 | 직장인, 대학생, 취준생, 프리랜서 |
| 특징 | MBTI/별자리/타로 등 자기이해 콘텐츠 소비자 |
| 지역 | 대한민국 (1차), 아시아 확장 예정 |

### 핵심 페르소나: 지현 (29세, IT 스타트업 마케터)

**상황:** 올해 이직할지 고민 중. 연애 패턴이 반복되는 것 같아 원인을 알고 싶음.

**니즈:**
- 출근길/잠들기 전 5분 안에 가볍게 사주 상담
- 이직, 연애, 재물 관점에서 나를 이해하고 싶음
- 그때그때 떠오르는 고민을 편하게 물어볼 AI 상담사

**기존 경험의 불만:**
- 점집은 비싸고 시간 잡기 어려움
- 사주 앱은 긴 리포트를 주는데 읽기 귀찮고 추가 질문 불가
- MBTI/타로는 재미있지만 깊이가 없음

> **"사주 상담은 오락 및 참고 목적입니다. 중요한 결정은 반드시 전문가와 상의하세요."**

- 온보딩 3페이지에 면책 고지 포함 (필수 동의)
- 채팅 화면 하단에 면책 배너 상시 노출
- AI 응답 규칙: 단정적 예언 금지 ("~할 것입니다" ✕ → "~하는 기운이 있습니다" ○)
- 건강 진단, 투자/재정 조언, 법률 조언 일체 금지
