## 성공 공식

### 1. 창업자 = 콘텐츠 크리에이터
- 2년간 TikTok에서 점성술 콘텐츠 → 22만 팔로워
- 팔로워가 곧 첫 유저 → 런칭 즉시 다운로드 폭발
- **사담 적용**: DK가 직접 사주 콘텐츠 만들거나, 점술 크리에이터와 협업

### 2. 동일 포맷 반복
- "별자리별 OO" 포맷 하나로 290개 영상
- 매번 새 포맷 만들 필요 없음 — 주제만 바꿈
- **사담 적용**: "12띠별 OO" 포맷 고정, 매주 주제만 교체

### 3. 다크 심리 후킹
- "무의식적으로 끌리는 독성 파트너" (470만 뷰)
- 불편하지만 무시 못하는 호기심 자극
- **사담 적용**: "사주에서 OO 나온 사람은 절대 OO하면 안 됩니다"

### 4. 시의성 콘텐츠
- 보름달, 수성 역행 등 천문 이벤트에 맞춰 콘텐츠
- 검색량 급증 시점에 영상 → 오가닉 노출 극대화
- **사담 적용**: 절기, 음력 이벤트 활용 ("동지 운세", "설날 신년운세")

### 5. 감정적 페이월
- "내 소울메이트 그림 보고 싶으면..." → 구독
- 기능이 아니라 궁금증으로 전환 유도
- **사담 적용**: "내 사주에서 재물운이 뭐라고 나오는지..." → 앱 다운로드

## 바이럴 영상 TOP 3 분석

### #1: "무의식적으로 끌리는 독성 파트너" (470만 뷰)
- 후킹: 다크 심리 + 별자리
- 포맷: 직캠 + 텍스트 오버레이
- 작동 원리: 12개 별자리 각각 개별 분석 → 리텐션 극대화

### #2: "보름달이 연애에 미치는 영향" (440만 뷰)
- 후킹: 시의성 (보름달) + 연애
- 작동 원리: 긴급성 ("지금 이 에너지를 활용하세요")

### #3: "수성 역행 중 연애 급변" (360만 뷰)
- 후킹: 트렌딩 이벤트 + "crazy turns"
- 작동 원리: 혼란 속 가이드 제공 → 앱이 해결책

## 사담 vs Starcrossed 비교

| 항목 | Starcrossed | 사담 |
|------|-------------|------|
| 체계 | 서양 점성술 (12별자리) | 사주팔자 (12띠, 10일간, 5오행) |
| 강점 | 이미 글로벌 인지도 | 동양 점술 = 차별화, "신비로움" |
| 약점 | 경쟁 많음 | BaZi 인지도 낮음 (교육 필요) |
| 기회 | - | "Korean fortune telling"은 K-culture 트렌드에 편승 가능 |
| 수익 | 구독 $70K/월 | 광고+구독 (현재 소규모) |

## 핵심 교훈

1. **Audience-first**: 콘텐츠 먼저, 앱은 나중
2. **포맷 하나 반복**: 새 포맷 실험 < 검증된 포맷 양산
3. **12분할 = 리텐션 치트키**: 띠/별자리별 콘텐츠
4. **K-culture 편승**: "Korean fortune telling"은 서양에서 신선함
5. **Build fast, launch lean**: MVP로 빠르게 런칭, 콘텐츠로 검증
